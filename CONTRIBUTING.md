# Contributing to iRacing Telemetry Analytics

First off, thank you for considering contributing to iRacing Telemetry Analytics! It's people like you that make this tool better for the whole sim-racing community.

## How Can I Contribute?

### Reporting Bugs
- Use the GitHub Issues tracker.
- Provide a clear and descriptive title.
- Describe the exact steps which reproduce the problem.
- If possible, include the `.ibt` file that caused the issue.

### Suggesting Enhancements
- Open a GitHub Issue with the tag `enhancement`.
- Explain why this enhancement would be useful.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the app still runs correctly.
4. Issue that pull request!

## Style Guide
- Follow PEP 8 for Python code.
- Use descriptive variable names.
- Document complex logic with comments.
